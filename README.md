# Personal Knowledge Base

A single-source-of-truth vault for notes, projects, and writing.

## Structure
- `01 - Note taking/` — how-to and note-making
- `02 - Projects/` — active project notes
- `03 - Reference/` — reference material
- `04 - Writing/` — drafts and writing notes
- `dd/` — daily notes (auto-created)
- `templates/` — note templates

## Capabilities
- **This PC** — used as primary editor via Obsidian
- **Phone** — Syncthing (Android/iOS) watches the same folder
- **Web** — GitHub Pages serves a browsable view

## Sync
- `git` (GitHub): fast, versioned, human-readable diffs
- `Syncthing`: bidirectional, low-latency folder sync
- Pages: static browsable view, refreshed from `gh-pages` branch

## Getting started
- Install Obsidian on this PC
- Install Syncthing on this PC and your phone
- Clone this repo, open `vault/` as the Obsidian vault
